# Changelog

All notable changes are documented here. This project follows semantic
versioning for tagged releases.

## [0.1.0] - 2026-08-11

### Added

- `audit`, `prepare`, `launch`, and `refresh` operating modes.
- Privacy/IP, portability, readiness, README, discovery, Repository Pulse, and
  adoption contracts.
- Deterministic public-surface auditor with redacted findings and optional
  Gitleaks history scanning.
- Token-safe Repository Pulse installer and white-background SVG renderer.
- English and Simplified Chinese repository documentation.
